# Все Банки РФ — Android-приложение

Обёртка над сайтом vsebankirf.ru: полноэкранный просмотр сайта, кнопка «назад»
работает как в браузере, скачивание файлов через системную загрузку, экран
«нет интернета» со кнопкой повтора.

## Как собрать APK (не нужен ни Android Studio, ни компьютер разработчика)

1. Зайдите на github.com, создайте бесплатный аккаунт (если его ещё нет).
2. Создайте новый репозиторий (New repository), любое имя, например `vsebankirf-android`.
   Можно приватный.
3. Загрузите в него все файлы из этой папки (на странице пустого репозитория —
   кнопка «uploading an existing file», просто перетащите всю папку целиком).
4. Откройте вкладку **Actions** в репозитории — сборка запустится сама
   (или нажмите «Run workflow», если не запустилась).
5. Подождите 2-4 минуты, зайдите в завершившийся запуск, внизу страницы —
   раздел **Artifacts**, там `vsebankirf-debug-apk`. Скачайте, распакуйте zip —
   внутри `app-debug.apk`.
6. Перекиньте APK на телефон (себе в Telegram/почту) и установите — Android
   спросит разрешение на установку из неизвестных источников, это нормально
   для тестовой сборки не из Google Play.

## Публикация в Google Play (когда решите, что приложение готово)

Для настоящего релиза (не тестового debug-APK) нужен подписанный `.aab`-файл.
Как это включить:

1. Заведите себе ключ подписи один раз (я подскажу команду `keytool`, если
   решите двигаться дальше) и сохраните пароли — если ключ потеряется,
   обновить уже опубликованное приложение будет нельзя.
2. Добавьте в репозитории (Settings → Secrets and variables → Actions) четыре
   секрета: `VB_KEYSTORE_B64`, `VB_KEYSTORE_PASSWORD`, `VB_KEY_ALIAS`,
   `VB_KEY_PASSWORD` — тогда сборка сама соберёт ещё и подписанный `.aab`,
   готовый к загрузке в Google Play Console.
3. Регистрация в Google Play Console (разовый взнос $25) и сама загрузка
   карточки приложения — это шаг, который нужно сделать лично вам (я не могу
   заводить аккаунты и вносить платежи за вас), но всё остальное — тексты
   описания, скриншоты, политику конфиденциальности — подготовлю.
